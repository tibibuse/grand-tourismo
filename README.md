# Grand Turismo

Un petit jeu de course en JavaScript, jouable directement dans le navigateur.

## Prérequis

Aucun package ni installation nécessaire.

## Lancer le projet

Ouvrez simplement `index.html` dans votre navigateur, ou lancez un petit serveur local :

```bash
python3 -m http.server 8000
```

Puis ouvrez : http://localhost:8000

## Contrôles

- Flèches gauche / droite
- ou clic gauche / droite sur la piste

## Objectif

- Éviter les voitures ennemies
- Gagner du score
- Survivre le plus longtemps possible

## Fichiers

- `index.html` : structure de la page
- `style.css` : interface et rendu du jeu
- `game.js` : logique du moteur, collisions et scoring

## Personnalisation

Tu peux facilement modifier :
- la vitesse du jeu
- la densité des obstacles
- les couleurs des voitures
- la disposition visuelle
